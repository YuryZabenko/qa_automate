1. Протестированные методы:
   add - сложение нескольких чисел
   multiply - умножение нескольких чисел
   subtraction - вычитание одного числа из другого
   divide - деление одного числа на другое
   exponentional - возведение числа в квадрат
2. Edge Cases:
   add - вызов без аргументов, отрицательные и смешанные числа
   multiply - вызов без аргументов, отрицательные и смешанные числа, умножение на 0
   subtraction - вычитание из 0, отрицательные значения
   divide - дробный результат, деление на 0, деление 0 на 0
   exponentional - возведение 0 в квадрат, возведение отрицательного числа
3. Параметризация использована в блоке для метода divide
4. Spy использован в блоке для метода subtraction,
   вызывается перед каждым тестом, и удаляется после кждого теста.
   в каждом тесте проверяется был ли вызван метод, сколько раз и с какими аргументами
