# qa_automate
Work
=======
> **Project:** Automation Exercise
> **Project:** http://automationexercise.com
> **Framework:** Playwright

#### Init

> **Установить зависимости:**
> npm install
> npx playwright install (установка браузеров)

#### Scripts:

> **Запуск тестов:** npm run tests Запуск тестов
> **Запуск тестов в режиме headed:** npm run tests:headed
> **Формирование отчета Allure:** npm run allure:generate
> **Просмотр сформированного отчета Allure:** npm run allure:open

---

## Описание директорий

| Папка             | Назначение                                                     |
| ----------------- | -------------------------------------------------------------- |
| **`components/`** | Переиспользуемые UI-компоненты (header, footer, modal)         |
| **`helpers/`**    | Вспомогательные функции (рандомные данные, блокировка рекламы) |
| **`pages/`**      | Page Object для каждой страницы                                |
| **`test-data/`**  | Тестовые данные (пользователи, продукты)                       |
| **`test-files/`** | Файлы для загрузки в тестах                                    |
| **`tests/`**      | Тест-кейсы (spec файлы)                                        |

---
